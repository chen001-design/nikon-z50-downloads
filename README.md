# Z50 Lab：自定义音效与菜单电压

[English](README.en.md) · [风险与已知限制](KNOWN-LIMITATIONS.md) · [下载 / Releases](https://github.com/chen001-design/nikon-z50-downloads/releases)

面向**第一代 Nikon Z50、C2.60 固件**的实验性工具套件：在电脑本地生成修改后的固件，并制作存储卡多音效文件。本页对应 **r5 实验候选**，请按发行条目的版本和 SHA-256 选择同版文件，勿混用旧工具包的说明或附件。

> [!CAUTION]
> **刷机需谨慎。** 修改固件可能造成相机无法启动、拍摄异常、数据丢失或永久损坏，也可能产生维修成本和停机时间。项目没有经过验证的救砖方案，不保证回刷一定可用。电脑构建成功、CRC 正确或文件哈希一致，只能确认所核文件及生成过程，不能证明每台相机都可安全安装。无法承担这些风险时，请保留官方固件，不进行实验性更新。

## 支持范围与功能

| 项目 | 当前行为与边界 |
|---|---|
| 适用机型 | 第一代 **Z50 / C2.60**；不适用于 Z50II、Z30、Zfc、Z8、ZR 或其他版本。 |
| M5 自定义音效 | 本项目内置三声备用音＋8 个固定 SD 音源槽位；机内可选源、试听、独立开启/关闭。内置音不是原厂快门声。开机默认为 **Built-in / Off**，选源不会自动开启；选择和 On 状态不跨重启保存。 |
| 菜单文字 | 默认组合的两个 Off 状态显示 `Shot sound: Off`，保留 `[ ]` / `[x]` 选择标记。 |
| 电量图标 | 保留原厂电量图标和低电提示。本版不启用旧五格实验补丁。 |
| 菜单电压 | 设定菜单末尾、“固件版本”之后显示 `Battery cache: … mV`。这是原厂标称缓存值，**不是容量百分比或实时测量**；0 保守显示未知，非零也不证明新鲜或物理准确。 |
| Windows 工具 | 64 位 Windows 10/11；随包提供所需 Python、Tk、音频转换器和固定构建依赖。微软 VC 运行库需由系统另行满足。 |

原 M5 有主要功能通过的历史用户反馈，但仍保留连续连拍几十张后可能出现自定义音效失效的问题。本版本的电脑生成反馈不等于完整机身、存储卡、拍摄模式或长期稳定性验收。详见[风险与已知限制](KNOWN-LIMITATIONS.md)。

## 1. 下载、校验、完整解压

从 [Releases](https://github.com/chen001-design/nikon-z50-downloads/releases) 选择与本说明对应、同时提供下列文件的发行条目：

| 文件 | 用途 |
|---|---|
| `Z50-Lab-Windows-Tools-r5.zip` | 普通用户运行包：固件构建器＋音效制作工具、必要依赖、许可证和说明。 |
| `Z50-Lab-Sources-r5.zip` | 同版完整对应源码与构建材料。开发、审查或重新分发时使用；普通运行无需解压它。 |
| `SHA256SUMS.txt` | 核对上述下载文件的 SHA-256。 |
| 发行说明 | 本版目标、验证范围及新增限制。 |

如果页面尚未提供这两个同版 ZIP，请勿用其他版本拼凑。首次运行前对照该发行条目的 `SHA256SUMS.txt`；可在下载目录打开 PowerShell，执行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Z50-Lab-Windows-Tools-r5.zip'
```

显示的 `Hash` 应与清单对应行一致，大小写不影响比较。不一致就停止使用并重新核对下载。

用 Windows 资源管理器将**整个运行 ZIP**正常解压到普通可写的本地文件夹，再从解压目录运行。不要在 ZIP 预览窗口内启动，不单独复制 EXE，不把旧目录与新包合并。无需管理员权限；若系统安全策略阻止启动，保留原提示，不关闭防护或删掉检查脚本绕过。

运行需要 64 位 Windows 10/11，以及 **Microsoft VC v14 x64 14.51.36247.0 或更高**。启动检查会说明缺失项，并给出微软官方取得途径；工具不会替你下载安装器。无需另装 Python、FFmpeg 或 Keystone。

## 2. 两个入口；Start-PublicBuildM5 是什么？

普通用户只需使用解压目录中的两个入口：

- **`启动固件构建器.cmd`**：打开固件构建控制台，输入官方固件，生成本版独立 EG 模块。
- **`启动多音源制作工具.cmd`**：打开“制作存储卡多音源”窗口，制作和试听音源文件。

`PublicBuildM5/Start-PublicBuildM5.ps1` 是内部必需组件：在加载程序前检查 Windows/VC 运行条件，并显示适用于随包官方 Python Windows 二进制内特定 Microsoft 代码的原许可条件。主构建脚本调用它，通过后才启动构建器。**它不能删，也无需单独双击。** 不接受提示时可输入 `N` 或取消，此次启动会停止。

旧包同名的 `Start-PublicBuildM5.cmd` 是另一种带参数的命令行启动器，正常分支也能启动 EXE；只有 `--dry-run` / `--check-runtime-only` 分支仅做检查。本联合包用主入口覆盖普通使用，因此省去这个备用 `.cmd` 和重复的内层用户入口。精简的是重复入口，必要检查和许可提示仍保留。

## 3. 在电脑生成固件

1. 从 [Nikon 官方 Z50 C2.60 下载页](https://downloadcenter.nikonimglib.com/zh-cn/download/fw/555.html) 自行取得原版 `Z_50_0260.bin`，本人阅读并决定官方下载条件。不要提供修改版、其他机型文件、已生成的 EG、私人恢复表或旧 M5。
2. 原版输入应为 **31,972,272 字节**，SHA-256：

   ```text
   69745c9e8f3156e936918e62a4a1fad18e7078e9ea3b95d8b8e08144b1542e49
   ```

3. 双击根目录 **`启动固件构建器.cmd`**。把原版文件拖入控制台，按 Enter；按提示本人阅读、决定是否接受本次启动所需的许可条件。
4. 等待本地恢复、编译、组合及完整目标校验完成。工具不会连接相机或扫描真实存储卡。
5. 成功后，在解压目录的 `PublicBuildM5/Generated-Firmware/时间戳/` 中查看 `EG163060.BIN` 和 `build-report.json`。每次使用新结果目录，已有结果不会被覆盖。

**默认 r5 组合的预期结果：**

```text
文件：EG163060.BIN
字节：31665490
SHA-256：eb33fab29b6ba337484961a852dd3a634f8c9573ac1b6631f1e20f692accd318
CRC16-XMODEM 尾值：665B；全文件余数：0
profile：m5-battery-cache
```

报告应为 `EXACT-PINNED-TARGET`，目标大小、SHA 和 profile 应匹配本版。可另用 `Get-FileHash` 核对 BIN。失败、缺报告或任一目标值不符时，保留日志/提示并停止，不手改校验值或强行安装。

`EG163060.BIN` 是**独立主模块**，不是官方完整 `Z_50_0260.bin` 更新容器。不要互相改名，也不要将 CRC 正确解释为获得 Nikon 官方签名或认可。

高级兼容选项 `--profile m5-only` 供复现冻结原 M5 使用，其完整 SHA-256 为 `09f539c078676509db12f759a4a9e2fe1516b7455e031635fd60bb677876d03e`；它不含菜单电压并保留原版文字。普通根入口默认生成上方的 r5 组合，无需选择此选项。

## 4. 制作音效文件

制作音效本身不会修改固件，不要求先插卡或连接相机。

1. 双击 **`启动多音源制作工具.cmd`**，本人决定启动条件后，打开“制作存储卡多音源”。
2. 窗口 8 行对应固定槽位 1—8。为需要的槽位点击“选择声音…”，可选 **WAV、MP3、AAC、M4A**；空槽位不生成文件。
3. 点击“制作所选槽位音源包”。超过约 0.5 秒的声音会逐槽询问是否只保留开头；任一槽位选“否”会取消整个制作。短声在末尾补静音。
4. 选择电脑上的保存父目录。工具新建 `Z50-多音源-槽位列表-输入摘要/` 制作包，例如 `Z50-多音源-01-08-…/`。同组输入在同一父目录产生相同目录名；已存在时拒绝覆盖，可选另一保存父目录。
5. **先在电脑试听 `previews/` 中的 WAV**，确认音色、开头和音量合适，再使用 `sd-card/` 中的 SND。

每个选定槽位始终对应同名文件：`SOUND01.SND` 至 `SOUND08.SND`。每个 SND 为 **96,032 字节**；工具在电脑按 48 kHz、双声道、16 位、24,000 帧准备声音，该约定不是机内时钟的实测标定。不要把 WAV 直接改名为 SND，也不要自行修改其头部或 CRC。

制作包还包含 `manifest.json`、试听 WAV 和使用说明；这些用于电脑核对，不需要随音源复制到卡上。工具不自动写入真实卡，也不替你安装支持读卡音效的固件。

## 5. 选择进行实验性安装前

先备份照片、需要保留的卡文件和设置资料，并确认备份可读取；保留自行取得的官方固件。准备稳定供电、充足电量和正常可读的存储卡。若需要格式化，先完整备份，再按相机说明操作；格式化会清除数据，本工具不会替你格式化。

以下沿用本工程已经使用的 **Z50 C2.60 独立 EG 路径**，只适用于第一代 Z50、当前已处于 C2.60 且能正常进入更新菜单的设备。它不是 Nikon 对实验模块的官方推荐，不是任意初始版本、降级或无法启动设备的通用指南。

1. 核对生成的默认 BIN 与上方 SHA、大小和报告。正常关机并等待卡访问结束后，用读卡器把**唯一一份 `EG163060.BIN` 放在卡根目录**。保持文件名，不把整个结果文件夹或 `build-report.json` 当固件，不同时混放其他固件候选。已有音源文件可保留。
2. 安全移除读卡器中的卡，在相机关机时插入；开机进入**设定/设置菜单（扳手图标）→固件版本**，检查模块是否被正常识别。
3. 如果没有更新选项、显示不兼容、名称/版本异常或有错误提示，**退出并停止**。不要改机型、改版本、把 EG 改名成官方整包、套用 Z8/ZR 方法或进入未知维修模式强行继续。
4. 只有在明确接受实验风险、文件被正常识别后，才按相机屏幕提示确认更新。**更新期间保持供电，不关机、不取电池、不拔卡。** 不设置自拟的强制断电超时；出现异常先保留屏幕信息。
5. 屏幕明确完成后，按其提示关机，再移除更新文件/卡并正常重启。版本头仍属 C2.60，不应期待显示一个新的官方版本号。检查 M5 菜单、无 `(factory)` 的 Off 文字和设定菜单末尾的缓存电压项，再谨慎检查普通拍照、保存与回看。

官方页面描述的是官方 `Z_50_0260.bin` 整包；本实验模块的识别与使用边界以本工程证据为限。删除卡上的更新文件不会撤销已写入的固件。即使设备仍能通过正常菜单重新安装官方版本，也不代表无法启动时可恢复；**没有已验证的救砖保证**。

## 6. 把音源用于相机

仅在已安装兼容 M5 多音源固件、相机正常关机且卡访问结束后，复制制作包 `sd-card/` 中需要的 **SND 文件本身**到卡根目录。不要把 `sd-card` 文件夹整个放进卡根，也不要复制 `previews` 下的 WAV 代替它们。

```text
存储卡根目录/
  SOUND01.SND
  SOUND08.SND
  DCIM/              ← 原照片目录，可保留
```

未选择的槽位不会由制作包生成或删除。正常开机时加载声音，之后可在机内反复选择；更换卡或替换 SND 应先正常关机，不热拔卡。现有 reader 对 FAT16、FAT32、exFAT 有受限读取实现，不代表所有容量、分区、卡况和文件布局均已实测。

机内入口为 **设定/设置菜单 → 蜂鸣音选项 → `Shot sound / pitch`**：

1. 选择 `Built-in (3 beeps)`（本项目的三声备用音，不是原厂快门声）或所需 `SD sound 1`—`SD sound 8` 并确认，确认当前选源标记。
2. 选源/聚焦可触发试听，**Off 时也可试听**；需要安静时请留意。
3. 需要拍摄自定义声音时，再单独选 `Shot sound: On`。只选音源不会自动开启。
4. 选 `Shot sound: Off` 可关闭新增拍摄音效，保留本次开机的选择；原厂对焦提示和机械快门仍遵循原厂设置。关机后不保持本次选源/On，下次从 Built-in/Off 开始。

不可用的 SD 项应先检查名称是否有双重扩展名、是否真为工具生成的 96,032 字节 SND、是否位于卡根，再正常重启。不要为了排查反复热拔卡或连续施加压力。

## 7. 查看菜单电压

在设定菜单末尾、“固件版本”之后查看 `Battery cache: … mV`，它与“蜂鸣音选项”同级。没有子菜单设置，也不需要按确认刷新。

- `--`：缓存为 0，保守按未知显示。
- 非零：显示原厂标称毫伏缓存值；未做物理标定，不等于精确电池容量。
- 只有原生文字记录实际重建时才重新读取缓存。重新打开、滚动、聚焦、重画或唤醒均**不保证得到新采样**。

不要用该数值自行推算精确百分比，或把它作为更新过程唯一的供电判断依据。原厂图标和低电警告继续保留。

## 8. 常见问题与停止条件

| 情况 | 建议 |
|---|---|
| 运行库/许可检查未通过 | 按提示补齐官方前置或取消；保留内部 PS1 和许可文件，不绕过门禁。 |
| 无法保存、输出已存在 | 选普通可写本地目录并使用新结果目录；不要管理员运行、修改系统安全标签或覆盖旧成果来试错。 |
| 转换器不可用/音频报错 | 确认 ZIP 完整解压、文件未被删改，输入是完整可播放的受支持音频；先保留错误原文。 |
| 选了 SD 声音但拍摄无声 | 确认已安装对应固件、按启动时机载入 SND、选源成功且单独开启 `Shot sound: On`。 |
| 显示不可用或发生普通运行异常 | 停止继续触发，保留完整提示和操作条件；不要反复刷写、热拔卡或做压力复现。 |
| 版本页类似 `F009:003` | 冒号表示故障格式；例如 `F012/003` 的斜杠可能只是正常音源显示。保留整串，不把计数当照片数或播放完成数。 |
| 更新正在进行且异常 | 保持供电，记录屏幕状态并按厂家支持处理；不要套用普通试听结束后的关机操作。 |

已知 `CA-M5-STRESS-01`：连续连拍几十张后可能出现自定义音效失效，精确阈值、概率和根因未定，未修复。**不建议为验证本说明而重做压力测试。** 项目不承诺每帧都重播、固定延迟或长期无限稳定。
